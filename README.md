Color Recognition Game using Python Tkinter

This project is a simple and interactive color recognition game built with Python and Tkinter.
The objective of the game is to type the color of the text displayed, not the actual word itself, as quickly as possible before the timer runs out.

Features
Interactive GUI built with Tkinter
Real-time score tracking
30-second countdown timer
Randomized color generation
Keyboard-based gameplay
Beginner-friendly Python project
How the Game Works

When the player presses the Enter key, the game starts and a random color word appears on the screen.
The displayed word and the text color are intentionally different.

The player must type the font color of the word instead of the written text.

Example

If the word displayed is:

BLUE

but the text color is Red, the correct answer is:

red

Each correct answer increases the player's score.
